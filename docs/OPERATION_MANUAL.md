# 渠沟清理标定与数字孪生监控系统 操作手册

> 适用版本：2.0.0（Qt 6.8.2 / C++17）
> 文档用途：面向现场操作人员与维护人员的日常使用说明。

## 1. 软件简介

本系统是水渠清理机器人上位机标定与数字孪生实时监控平台，提供：

- 渠道与障碍物标定数据管理；
- 0-100m 清洗轨迹、墙体贴条与柱状图实时数字孪生展示；
- 清洗头状态机与多级报警联动；
- 模拟视觉监控画面；
- 障碍物数据编辑、撤销/重做与 JSON 标定数据导出。

## 2. 运行环境与启动

运行环境：

- Windows 10/11（64 位）；
- 已部署的发布目录 `deploy/`（包含 exe 与 Qt 运行时，无需安装 Qt 环境）。

启动方式：

```bash
deploy/ChannelInspectionCalibration.exe
```

启动后窗口标题显示“渠沟清理标定”，主界面即进入标定与监控工作台。

## 3. 界面总览

| 区域 | 说明 |
| --- | --- |
| 左侧边栏 | 渠道编号、长度、操作员、检查日期；随机生成、PDF、导出、开始/停止模拟 |
| 报警中心 | 顶部横条：系统状态、活动报警数、呼吸报警灯；点击展开报警历史 |
| 水箱/清洗头状态区 | 水箱液位、出水流量、剩余时间、预估剩余清洗、完成率；清洗头状态与压力 |
| 数字孪生图 | 清洗轨迹、混凝土墙体、障碍柱状图、坐标轴与图例 |
| 折叠面板 | 清洗头实时监控、水资源与工时预估、现场作业派工单、障碍物数据明细、工作日志 |

## 4. 标准操作流程

1. **填写标定信息**：在左侧栏填写渠道编号、长度（m）、操作员、检查日期。
2. **准备障碍物数据**：
   - 点击“随机生成新现场”自动生成随机障碍物；或
   - 在“障碍物数据明细”表格中手动添加/修改。
3. **开始模拟**：点击“开始模拟”，观察数字孪生轨迹推进、水箱液位下降、报警中心与视觉监控画面。
4. **处理报警（如有）**：查看报警中心等级与呼吸灯颜色，按需“确认报警”；清洗头损坏时先“确认”再点击“清洗头损坏已修复”。
5. **停止模拟**：点击“停止模拟”。
6. **导出数据**：点击“导出标定数据”，选择路径保存 JSON 文件。

## 5. 功能详述

### 5.1 左侧边栏配置

- **渠道编号**：当前作业渠道名称，例如 `A1路段主沟渠`；
- **长度(m)**：渠道总长，范围 1-10000m；
- **操作员 / 检查日期**：记录作业人与检查日期，用于报表与日志。

修改任一配置后，数字孪生与报表会自动刷新。

### 5.2 随机生成新现场

点击后自动生成 2-5 个随机障碍物（泥沙、泥块、石头、树枝、垃圾、积水），重置模拟状态并刷新数字孪生图。

### 5.3 障碍物数据明细

表格支持：

- 下拉选择障碍物类型（泥沙 / 泥块 / 石头 / 树枝 / 垃圾 / 积水）与严重度（轻度 / 中度 / 重度）；
- 修改起止里程与备注；
- “添加 / 删除”增删行；
- “上一步 / 下一步”撤销与重做。

> 删除前请先选中表格中的目标行。

### 5.4 开始 / 停止模拟

- 开始模拟后，传感器按 100ms 周期刷新，清洗头沿渠道推进；
- 设备破损时模拟自动停止；
- 停止后按钮状态恢复，可重新开始或修改数据。

### 5.5 数字孪生图

- **轨迹区**：浅蓝色水区 + 混凝土墙体，清洗头沿轨迹移动并显示当前位置；
- **墙体贴条**：与下方柱状图 1:1 投影，相同障碍物颜色一致；
- **柱状图**：按严重度高度显示障碍（重度 / 中度 / 轻度）；
- **图例**：石头/泥块红色、树枝/泥沙/积水绿色、垃圾深灰色；
- **显示模式**：显示全部 / 仅看重度 / 仅看中度 / 仅看轻度。

### 5.6 报警中心与呼吸灯

| 呼吸灯颜色 | 含义 | 横条颜色 |
| --- | --- | --- |
| 绿色（慢呼吸） | 正常，无报警 | 绿 |
| 黄色（中速） | 警告报警 | 橙/黄 |
| 红色（快速） | 严重/危急报警 | 红 |

点击横条可展开报警历史，支持“确认报警”；活动报警数显示在横条右侧。

### 5.7 清洗头实时监控

“清洗头实时监控”面板展示模拟摄像头画面（约 7FPS）、运行参数（位置、水压、流量、运行状态）。画面尺寸固定，推帧时不会挤压右侧参数面板。

### 5.8 数据导出

“导出标定数据”将当前渠道信息与障碍物数据保存为 JSON 文件，便于归档或后续导入真实硬件系统。

> “生成现场派工单PDF”当前为占位功能，正式版前请以 JSON 导出为准。

## 6. 常见问题

**Q1：点击开始模拟后画面没有变化？**
检查是否先填写了渠道长度并点击“开始模拟”；如设备破损会自动停止，请确认报警中心状态。

**Q2：数字孪生图中墙体颜色与柱状图不一致？**
颜色逻辑已统一，请确认使用最新版本；如仍异常，检查障碍物类型是否为自定义文本。

**Q3：视觉监控画面上下伸缩？**
请使用最新构建版本；视频区域尺寸已锁定，不会随帧推送变化。

**Q4：导出 JSON 文件打不开？**
使用文本编辑器或支持 JSON 的工具打开，文件为 UTF-8 编码。

## 7. 注意事项

- 修改障碍物数据后，请重新“开始模拟”使引擎加载最新数据；
- 报警历史为内存数据，重启软件后清空；
- 工作日志在完成率达到 100% 时自动生成一条记录。
